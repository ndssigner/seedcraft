Seedcraft Sequences

A BIP-39 seed as a sequence of objects: beads, charms, bricks… via its CompactSeedQR. Format draft v{{FORMAT_VERSION}}.

This page cannot connect anywhere

Its Content-Security-Policy forbids every network request: it only runs the script and style inside this one file. It works with the computer offline, and it should be used that way.

Check this file before trusting it

A page cannot vouch for itself: a modified copy could claim anything. Check it with your operating system instead, and compare the result with the SHA-256 published with the release at github.com/ndssigner/seedcraft:

macOS / Linux:  shasum -a 256 seedcraft-sequences.html
Windows:        certutil -hashfile seedcraft-sequences.html SHA256

The file is reproducible: building it from the repository at the same version (node web/build.mjs) gives the same SHA-256.

What it is for

To learn and try the Seedcraft Sequences format (specification SPEC-sequences.md) with test seeds. A seed typed into a computer is exposed to everything that runs on it: encode real seeds on an air-gapped device.
